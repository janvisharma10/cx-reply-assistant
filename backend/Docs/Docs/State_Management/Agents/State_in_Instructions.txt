State in Instructions

Copy page

Reference session state variables directly inside an agent’s instruction templates.

Use session state variables directly in agent instructions. Initialize the state, then reference the variables in your instruction templates.
1
Create a Python file

session_state_in_instructions.py
from agno.agent import Agent
from agno.models.openai import OpenAIResponses

agent = Agent(
    model=OpenAIResponses(id="gpt-5.2"),
    session_state={"user_name": "John"},
    instructions="Users name is {user_name}",
    markdown=True,
)

agent.print_response("What is my name?", stream=True)
